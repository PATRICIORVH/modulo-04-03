# Ejercicio POO en JavaScript

Proyecto del módulo 0 sobre programación orientada a objetos en JavaScript.

## Contenido

- `index.html`: página principal que carga los ejercicios.
- `taxis.js`: modelado de clases para taxis urbanos usando herencia.
- `sony.js`: catálogo simplificado de productos Sony Chile usando clases.
- `sumatoria.js`: clase Sumatoria con número base aleatorio y botones en la página.

## Cómo ejecutar

1. Clonar o descargar este repositorio.
2. Abrir `index.html` en un navegador (o usar Live Server en Visual Studio Code).
3. Abrir la consola del navegador para ver los resultados de cada ejercicio.
